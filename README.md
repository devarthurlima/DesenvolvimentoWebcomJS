# 💻 Desenvolvimento de Interfaces Web com JavaScript

Repositório dedicado ao armazenamento de exercícios, práticas e projetos desenvolvidos durante o curso **Desenvolvimento de Interfaces Web com JavaScript (EAD)**, realizado pela **Universidade do Trabalho Digital (UTD / Instituto CENTEC)**.

---

## 📌 Sobre o Curso

* **Instituição:** Universidade do Trabalho Digital (UTD) / Instituto CENTEC
* **Carga Horária:** 120 horas/aula
* **Período:** 11/05/2026 a 04/08/2026
* **Instrutor:** Osvaldo Souza Arruda Neto

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

* **HTML5 & CSS3:** Estruturação semântica e estilização de páginas web.
* **JavaScript:** Lógica de programação, manipulação de arrays e Programação Orientada a Objetos (POO).
* **Node.js:** Execução de JavaScript no backend e gerenciamento de pacotes.
* **React:** Construção de interfaces dinâmicas e baseadas em componentes.
* **Git & GitHub:** Controle de versão e publicação de código.
